# Lens: visual design

Whether the change looks like it belongs in this app. Before you judge it, read
what it should match: the theme or design-token configuration, the global
stylesheets, and the neighbouring components. Look at the page at desktop and
phone widths.

- The same colours, type scale, spacing, radii and backgrounds as the
  components around it.
- It uses the existing styling system and classes. Flag new one-off styles or
  hard-coded colours where a theme value exists.
- Alignment, spacing rhythm and hierarchy hold up, and nothing overflows at
  phone width.
- Text contrast is readable.

CHANGES is for visible inconsistencies or breakage. Matters of taste go under
Notes.
