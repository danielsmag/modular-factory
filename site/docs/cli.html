CLI

mfactory on your PATH after install.sh --global, or .factory/bin/mfactory from anywhere in a repository. A job is its id (004-dark-mode), the number in its id (004), or its issue (12 or #12).

install and init are the same command. hook exists for the Claude Code stop hook and is left out of the help list.

Install and maintain

install --tool TOOL

Install the factory into this repository. --tool is claude, cursor, or codex. Repeat it for several. Default: claude. Never overwrites factory.toml.

sync --check

Write the agent and skill files from factory.toml. --check changes nothing and exits 1 if anything is out of date.

doctor --skip-checks

Check that everything a run needs is in place, including the checks on a clean copy of the base branch. --skip-checks leaves that run out.

upgrade --version --source --self --all

Upgrade the global CLI, every project in the workspace, and the checkout you are in when that checkout is installed and not listed. Leaves factory.toml and .factory/jobs/ alone. --version is a tag such as v0.2.0 (default latest). --source is a local copy. --self updates only the global CLI. --all upgrades only the projects in the workspace. One project failing does not stop the others.

uninstall --config --labels

Remove the factory from this repository. factory.toml stays unless --config is set. --labels deletes the factory labels on GitHub.

status --all

The installed version, and whether generated files are current. --all prints one row per project in the workspace. Outside a repository, status shows the workspace.

version

Print the factory's version.

See the configuration

config show --json

The merged configuration, and which file set each value.

graph --json

The pipeline in effect.

models

The model and effort of each agent, per tool.

skills

The project's skills and which agents read them.

Run jobs

The /mfactory skill uses these. You can run them yourself. The orchestrator is still what starts agents.

queue --json

What to run now. --json prints one JSON array with each issue's title, URL, dates, author and labels.

create <issue>

Start a job for a labeled issue.

file <title>

Open an issue in the queue and print its address. The issue's text is read from standard input.

tracker show --json

With a Jira board: each step, its status and its board column, and what is wrong with them. Exits 1 when the board has a problem.

tracker sync

With a Jira board: move every unfinished job's card to its step's status. Run it after the board or [tracker.jira.columns] changed.

next <job>

Say what the orchestrator must do for a job. Runs checks, merge, and verify itself.

done <job> --reply

Read the outcome of the step an agent finished. --reply reads the agent's reply from standard input. Cursor and Codex intake need this.

answer <job> <outcome> [text...]

Reply to a step that waits for a person. The outcome is one the step allows, such as approve, changes, feedback, answer, or reject. Words can follow, or come on standard input.

close issue <job> --not-planned

Close the job's issue on GitHub, as completed or, with --not-planned, as not planned. The job is not touched. The factory never closes an issue on its own.

close job <job>

End the job as done from any step, and remove its worktree. The issue and any open pull request stay as they are.

route <job>

Which agents a job uses.

checks

Run [checks].commands in the current directory.

Dashboard

dashboard --port --no-open

Serve the read-only dashboard for every project in the workspace. Default port 4747. Stays in the foreground until Ctrl C. The page comes with the global install: a project's .factory/bin/mfactory hands dashboard, start and stop to the global mfactory.

start dashboard

Serve the dashboard and return. Same flags as dashboard.

stop [dashboard]

Stop the background dashboard.

Workspace

mfactory workspace with no subcommand lists the projects. mfactory install adds the checkout it installs into.

workspace init

Write workspace.toml in the current directory. A file here, or FACTORY_WORKSPACE, wins over ~/.mfactory/workspace.toml.

workspace add [path]

Add this repository, or a path, to the workspace. The factory must be installed there.

workspace remove [path]

Remove this repository, or a project by its path or folder name.

workspace list

List the projects in workspace.toml.

workspace queue --concurrency N

Run each project's own factory queue. --concurrency caps new and resume rows across projects. Default: [workspace].concurrency.
